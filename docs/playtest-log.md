# 8 案试玩记录表

每案完成 2 轮内部试玩后，将结果填入下表。填写完成后用于：
- 调整 `actionPointLimit`（行动点过多/过少）
- 识别需要加强或削弱迷惑性的误导证据
- 确认复盘反馈质量是否到位
- 判断是否需要把反复出现的误判固化为新 lint 规则

---

## 验收标准（每案）

- [ ] 只看断案选项（遮住勘查），不能稳定猜中正确答案
- [ ] 不做断案、只读勘查文本，不能直接读到最终真相
- [ ] 至少 1 条错误路径能让玩家认真犹豫 60-70%
- [ ] 行动点剩余在 0-2 点之间（太多说明太松，太少说明太紧）
- [ ] 复盘能解释"错误链为何看起来合理 + 哪里断了"
